# 真实任务：可审计的模型交付包

## 背景

训练团队把一个 PyTorch 模型交给端侧部署团队。仅发送一个 `.pth` 文件无法说明模型结构、输入契约、导出版本或 Runtime 结果。本任务要求你交付一个第三方可以重新执行和审计的最小模型包。

## 必须交付

在 `artifacts/` 中生成：

- `challenge_model.pth`：只包含 `state_dict`；
- `challenge_model.onnx`：输入名 `input`、输出名 `output`，Dynamic Batch；
- `delivery_manifest.json`：输入 Shape/Dtype、Opset、Runtime、固定输入、PyTorch 输出、ORT 输出、误差和工程结论。

## 验收标准

1. Checkpoint 与 ONNX 都存在且非空；
2. ONNX 通过 Checker，输入 Batch 维为动态；
3. 固定输入 Shape 为 `[4, 8]`，输出 Shape 为 `[4, 3]`；
4. PyTorch 与 ORT 最大绝对误差 ≤ `1e-5`；
5. Manifest 中的输出和误差可由验收器复算；
6. 至少 100 个中文字符说明输入契约、版本兼容、CPU Fallback、数值容差与目标设备 Benchmark 风险。

运行 `python challenge_starter.py` 完成 TODO，随后运行 `python validate.py --challenge artifacts/delivery_manifest.json`。

<details><summary>提示 1：保存什么</summary>训练权重优先保存 `state_dict`，加载时必须先以相同结构重建模型。</details>
<details><summary>提示 2：动态 Batch</summary>导出时为输入和输出的第 0 维设置同名动态轴 `batch`。</details>
