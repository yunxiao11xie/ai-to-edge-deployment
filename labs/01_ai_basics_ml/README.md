# 第 1 章实验室：AI 基础与机器学习

> 本目录是仓库第一份“讲义 + 完整实验 + 练习 + 验收 + 真实任务”样板。

## 学习入口

| 环节 | 作用 | 入口 |
|---|---|---|
| 阅读讲义 | 建立 AI、机器学习、训练、推理和评估的知识框架 | [第 1 章讲义](../../从AI基础到端侧部署优化/01_AI基础与机器学习.md) |
| 完整实验 | 运行回归、分类、聚类和 Q-learning 的参考实现 | [完整实验 Notebook](./完整实验.ipynb) |
| 练习 | 独立补全四项核心任务，并接受分项检查 | [练习 Notebook](./练习.ipynb) |
| 验收 | 对练习变量或真实任务提交物进行机器检查 | [`validate.py`](./validate.py) |
| 真实任务 | 完成一个端侧设备故障预警原型 | [真实任务说明](./真实任务_设备故障预警.md) |

## 推荐顺序

```text
先阅读讲义的本章导读和核心概念
        ↓
运行完整实验，观察输入、输出和指标
        ↓
关闭完整实验，独立完成练习 Notebook
        ↓
运行练习末尾的统一验收
        ↓
完成设备故障预警真实任务
        ↓
使用 validate.py 验收提交物
```

完整实验是经过验证的参考实现，不是必须背诵的标准答案。练习和真实任务会改变问题形式，单纯复制完整实验不能直接通过最终任务。

## 运行环境

| 项目 | 要求 |
|---|---|
| Python | 3.10 或更高版本 |
| 运行位置 | Windows、Linux、macOS 或普通云端 Notebook |
| GPU | 不需要 |
| 网络 | 安装依赖后不需要 |
| 预计时间 | 完整实验 60～90 分钟；练习 90～120 分钟；真实任务 2～4 小时 |

在本目录创建独立环境并安装依赖：

```bash
python -m venv .venv
python -m pip install -r requirements.txt
```

激活环境后，从本目录启动 Jupyter：

```bash
jupyter lab
```

## 验收方式

练习 Notebook 最后一格会读取当前运行状态，分别检查：

- 回归模型是否完成训练、预测数量和 R² 是否合理；
- 分类 Pipeline 是否完成训练，Accuracy 是否达到基础要求；
- K-Means 是否生成三个簇，轮廓系数是否合理；
- Q-learning 是否学会从状态 0 到达终点。

通过后会生成：

```text
artifacts/exercise_result.json
```

真实任务完成后，运行：

```bash
python validate.py --challenge artifacts/challenge_submission.json
```

验收器会根据提交的测试集编号和预测结果重新计算指标，不能只填写一个好看的分数。

## 五层结构的设计目的

| 层 | 主要回答的问题 |
|---|---|
| 讲义 | 为什么这样做？ |
| 完整实验 | 一条正确、可运行的流程是什么样？ |
| 练习 | 我能否独立补全关键步骤？ |
| 验收 | 有什么证据证明结果正确？ |
| 真实任务 | 换一个问题后，我能否迁移所学能力？ |
