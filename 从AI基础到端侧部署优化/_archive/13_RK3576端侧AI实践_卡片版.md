# 13_RK3576端侧AI实践

> **所属路线**：AI 学习路线 · 最终实践篇  
> **定位**：把前面 `PyTorch → LLM → Runtime → AI Compiler → GPU Kernel → RKNN → RKLLM` 的知识全部落到一块真实 RK3576 开发板上，形成一个**可复现、可测量、可调试、可展示、可写进简历**的端侧 AI 工程。  
> **核心项目 A**：Qwen3.5-2B → RKLLM W4A16 → RK3576 RKNPU → C++ Runtime → HTTP Server → RAG / Agent  
> **辅助项目 B**：MobileNet / YOLO → RKNN-Toolkit2 → `.rknn` → RK3576 RKNPU → C++ Runtime / Zero Copy / RGA  
> **开发环境假设**：Windows 主机 + Ubuntu 虚拟机；RK3576 板端 Ubuntu / Linux  
> **当前官方主线版本参考**：
>
> - RKNN-Toolkit2：v2.3.2
> - RKNN-LLM / RKLLM：v1.3.0
> - RKLLM v1.3.0：官方支持 Qwen3.5 与 RK3576
>
> **资料检查日期**：2026-08-25  
> **最终目标**：不是“成功跑一次模型”，而是交付一套完整的 Edge AI Engineering Portfolio。

```text

```

4B：

```text
能力更强
```

但：

```text
速度下降明显
内存压力更高。
```

2B：

```text
能力
速度
内存
```

处于比较适合 RK3576 学习与展示的中间点。

# 75. 最小转换逻辑

```python
from rkllm.api import RKLLM

model_path = "/path/to/Qwen3.5-2B"
save_path = "./qwen3.5-2b-w4a16-rk3576.rkllm"

llm = RKLLM()

ret = llm.load_huggingface(
    model=model_path,
    device="cpu",
)

if ret != 0:
    raise RuntimeError("load_huggingface failed")

ret = llm.build(
    do_quantization=True,
    optimization_level=0,
    quantized_dtype="w4a16",
    quantized_algorithm="grq",
    target_platform="rk3576",
    num_npu_core=2,
    dataset="./data_quant.json",
    max_context=4096,
)

if ret != 0:
    raise RuntimeError("build failed")

ret = llm.export_rkllm(save_path)

if ret != 0:
    raise RuntimeError("export failed")
```
