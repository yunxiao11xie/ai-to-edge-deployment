# 6. 什么是 Neural Network？

最简单可以理解为：

> **大量可学习的数学函数按照一定结构连接起来。**

例如：

```text
Input
 ↓
Layer 1
 ↓
Layer 2
 ↓
Layer 3
 ↓
Output
```

每个 Layer：

```text
Input Tensor
    ↓
Linear Transformation
    ↓
Nonlinear Activation
    ↓
Output Tensor
```

整个网络：

```text
f(x; θ)
```

其中：

```text
x = Input

θ = 所有可学习参数
```

训练的目标：

```text
找到 θ

使：

f(x; θ)

尽可能接近真实目标 y
```

# 7. 从一个 Neuron 开始

一个最基础的人工神经元：

```text
x1 ──w1──┐
x2 ──w2──┤
x3 ──w3──┤
         ├── Σ + b ── Activation ── y
...      │
xn ──wn──┘
```

数学形式：

```text
z = w1*x1 + w2*x2 + ... + wn*xn + b

y = activation(z)
```

向量形式：

```text
z = w · x + b

y = σ(z)
```

这实际上就是：

```text
Linear
+
Activation
```

# 8. Weight 和 Bias

Weight：

```text
w
```

可以理解为：

> 每个输入 Feature 对输出的重要程度。

Bias：

```text
b
```

可以理解为：

> 给整个线性变换增加一个可学习偏移。

因此一个 Neuron 的核心参数：

```text
[w1, w2, ..., wn, b]
```

训练的目标就是调整这些参数。

# 10. 为什么必须有 Activation Function？

假设：

```text
Layer 1:
h = W1 x

Layer 2:
y = W2 h
```

代入：

```text
y = W2 W1 x
```

令：

```text
W = W2 W1
```

那么：

```text
y = Wx
```

也就是说：

> 两层 Linear Layer 叠起来仍然只是一个 Linear Layer。

即使：

```text
100 层 Linear
```

本质还是：

```text
1 层 Linear
```

因此必须加入：

> **Nonlinear Activation Function**

例如：

```text
ReLU
Sigmoid
Tanh
```

这样：

```text
Linear
↓
Nonlinear
↓
Linear
↓
Nonlinear
```

才能拟合复杂函数。

# 11. ReLU

ReLU：

```text
ReLU(x) = max(0, x)
```

即：

```text
x < 0
↓
0

x > 0
↓
x
```

图像大致：

```text
y
│       /
│      /
│     /
│____/________ x
     0
```

ReLU 的优势：

- 计算简单
- 正数区域梯度稳定
- 深度网络中非常常见

在 micrograd 中，ReLU 的局部梯度逻辑非常直观：

```text
x > 0
gradient = 1

x <= 0
gradient = 0
```

源码：

- [micrograd engine.py - relu](https://github.com/karpathy/micrograd/blob/master/micrograd/engine.py)

# 12. Sigmoid

Sigmoid：

```text
σ(x) = 1 / (1 + exp(-x))
```

输出范围：

```text
0 ~ 1
```

因此过去经常用于：

```text
Binary Classification Probability
```

但深层隐藏层中现在通常较少使用。

原因之一：

> 输入绝对值很大时梯度很小，容易出现 Vanishing Gradient。

---

# 13. Tanh

Tanh 输出：

```text
-1 ~ 1
```

相比 Sigmoid：

```text
zero-centered
```

在经典 RNN 中经常出现。

# 15. Layer

一个 Neuron：

```text
Input
 ↓
1 Output
```

一个 Layer：

```text
Input Vector
    ↓
多个 Neuron
    ↓
Output Vector
```

数学上：

```text

```

其中：

```text
x: [input_dim]

W: [output_dim, input_dim]

b: [output_dim]

y: [output_dim]
```

所以：

> 一个 Fully Connected Layer 本质上就是一次 Matrix Multiplication + Bias。

这件事非常重要。

因为后面：

```text

```


# 18. 用 PyTorch 写一个最小 MLP

```python
import torch
import torch.nn as nn

class MLP(nn.Module):
    def __init__(self):
        super().__init__()

        self.net = nn.Sequential(
            nn.Linear(15, 64),
            nn.ReLU(),

            nn.Linear(64, 32),
            nn.ReLU(),

            nn.Linear(32, 5)
        )

    def forward(self, x):
        return self.net(x)
```

```text
15
```

是输入 Feature 数。

```text

```

是类别数。

# 20. 为什么 Deep Learning 需要 Tensor？

因为现实中不会一个标量一个标量地算。

例如：

```text
32 张图
每张 3×224×224
```

如果每个元素单独计算，效率极低。

所以：

```text
大量 Scalar Operation
        ↓
Vectorize / Tensorize
        ↓
Tensor Operation
        ↓
CPU SIMD / GPU Parallel
```

micrograd 故意只使用 scalar。

这是为了：

> 看清楚每一个加法、乘法和梯度传播。

PyTorch 使用 Tensor。

这是为了：

> 高性能并行计算。

所以：

```text
micrograd
=
原理

PyTorch Tensor
=
工程化
```

# 29. Gradient 到底是什么？

假设：

```text
Loss = L(w)
```

Gradient：

```text
dL/dw
```

表达：

> 如果参数 `w` 稍微改变一点，Loss 会怎样变化？

如果：

```text
dL/dw > 0
```

说明：

```text
w 增大
→
Loss 倾向增大
```

那么为了减小 Loss：

```text
w 应该减小
```

反之亦然。

---

# 30. Gradient 的几何意义

Gradient 指向：

> 函数增长最快的方向。

所以训练时：

```text
Gradient Descent
```

沿反方向：

```text
-Gradient
```

下降。

# 33. Chain Rule：Backprop 的数学核心

假设：

```text
x → y → z
```

其中：

```text
y = f(x)

z = g(y)
```

我们想知道：

```text
dz/dx
```

链式法则：

```text
dz/dx
=
dz/dy × dy/dx
```

如果计算图更长：

```text
x
 ↓
a
 ↓
b
 ↓
c
 ↓
Loss
```

那么：

```text
dLoss/dx
=
dLoss/dc
×
dc/db
×
db/da
×
da/dx
```

这就是：

> Backpropagation 的本质。

# 34. 为什么叫 Backpropagation？

Forward：

```text
x
↓
a
↓
b
↓
prediction
↓
loss
```

Backward：

```text
loss
↑
prediction
↑
b
↑
a
↑
parameters
```

从 Loss 开始，逐层计算：

```text
Loss 对每个 Parameter 的 Gradient
```

所以叫：

```text
Backward Propagation
```

```text
├── data
├── grad
├── _prev
├── _op
└── _backward
```

---

# 36. 局部导数

例如：

```text
z = x + y
```

那么：

```text
dz/dx = 1

dz/dy = 1
```

所以 backward：

```text
x.grad += z.grad

y.grad += z.grad
```

---

对于：

```text
z = x * y
```

有：

```text
dz/dx = y

dz/dy = x
```

因此：

```text
x.grad += y * z.grad

y.grad += x * z.grad
```

这正是 Chain Rule：

```text
Local Gradient
×
Upstream Gradient
```

---

# 37. Backward 的两部分

每一个 Operation：

```text
Forward
+
Local Backward
```

例如：

```text
Multiply
```

Forward：

```text
z = x * y
```

Backward：

```text
x_grad = y * z_grad

y_grad = x * z_grad
```

这就是所有大型 Autograd Framework 的基本思想。

只是现实中的：

```text
PyTorch
TensorFlow
JAX
```

支持的是：

```text
Tensor Operation
GPU
Broadcast
复杂 Operator
高性能 Kernel
```

---

# 38. Topological Sort

计算图：

```text
a
 \
  c
 /
b
 \
  d
   \
    loss
```

Backward 时不能乱序。

必须：

```text
先算下游
再算上游
```

micrograd 的 `backward()` 会先建立：

```text
Topological Order
```

然后：

```text
reverse
```

从 Loss 反向执行每个节点的 `_backward()`。

这就是 `loss.backward()` 最值得理解的核心逻辑。

---

# 39. 为什么 Gradient 要累加？

假设：

```text
x
├── path A ──┐
└── path B ──┤
             ↓
           Loss
```

那么：

```text
x
```

通过多个路径影响 Loss。

总梯度：

```text
dL/dx
=
path_A_gradient
+
path_B_gradient
```

因此 micrograd 使用：

```python
self.grad += ...
```

而不是：

```python
self.grad = ...
```

这也解释了 PyTorch 中为什么经常需要：

```python
optimizer.zero_grad()
```

---

# 40. 为什么 PyTorch 每轮要 zero_grad？

PyTorch 默认：

> Gradient 会累计。

所以如果：

```python

loss.backward()
```

而没有清零：

```text
gradient
=
上一次
+
这一次
```

正常训练：

```python
optimizer.zero_grad()

output = model(x)

loss = loss_fn(output, y)

loss.backward()

optimizer.step()
```

这个顺序必须形成肌肉记忆。

# 96. 一个完整 PyTorch Classification 示例

```python
import torch
import torch.nn as nn

model = nn.Sequential(
    nn.Linear(15, 64),
    nn.ReLU(),

    nn.Linear(64, 32),
    nn.ReLU(),

    nn.Linear(32, 5)
)

loss_fn = nn.CrossEntropyLoss()

optimizer = torch.optim.Adam(
    model.parameters(),
    lr=1e-3
)

for epoch in range(20):

    model.train()

    for x, y in train_loader:

        optimizer.zero_grad()

        logits = model(x)

        loss = loss_fn(logits, y)

        loss.backward()

        optimizer.step()
```
